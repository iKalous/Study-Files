### 数据类型

#### 矩阵相关

##### 矩阵

- 定义一个矩阵：
$A = [1 2 3; 4 5 2; 3 2 7; 4 6 8]$
实际效果是：
$A =$
    | 1 | 2 | 3 |
    | :--: | :--: | :--: |
    | 4 | 5 | 2 |
    | 3 | 2 | 7 |
    | 4 | 6 | 8 |

- 矩阵**转置**：
    $B = A'$
- 矩阵**拉长**：
    $C = A(:)$
- 矩阵**求逆**
    $D = inv(A)$
    - 补充：$pinv(A)$ 同样可以求A的逆
- 建立一个**单位矩阵** $eye(n)$ 
  形成一个$n*n$的单位矩阵
- 建立一个**全零矩阵** $zero(m,n)$
- 全$1$矩阵$ones(n,m)$
- **对角矩阵**
$G = diag([1,2,3])$

##### 矩阵操作

- **重复操作**：
    对于矩阵B
    $C = repmat(B,n,m)$
    表示把B作为元素放置在$n*m$的棋盘上
- 矩阵的 **四则运算** (对于矩阵A和B)
    - 加 $C = A + B$
    - 减 $C = A - B$
    - 矩阵乘法 $C = A * B$
    - 矩阵对应项相乘$C = A$ $.* B$
    - 矩阵除法[^1] $C = A / B$
    - $C = A$ $./ B$ 原理和乘法相同

##### 矩阵的下标

$:$ 几乎在所有的语言中$:$都代表**取全部**

- $B = A(i,j)$
    其中$i,j$可以是具体的数值，也可以是$:$
- 查找元素 $[m,n] = find(条件，如A > 20)$
    将会返回下标$(m,n)$，但是会分开返回所以并不是特别好用


##### 随机数
- $rand$：生成均匀分布的伪随机数，分布在$(0,1)$
    rand(m,n) 生成m行n列的随机数
- $randn$ 生成标准**正态分布**的伪随机数(均值为$0$，方差为$1$)
    语法同上
- $randi$生成均匀分布的伪随机**整数**
    - $randi(Max)$, 在$(0,Max)$上生成均匀分布的随机整数
    - $randi(Max,m,n)$在$(0,Max)$上生成$m*n$的随机矩阵
    - $randi([Min,Max],m,n)$即是在上一个的基础上限定区间为$(Min,Max)$

##### 元胞数组

$A = cell(1,6)$

可以简单认为是一个彩虹数组。

其元素可以是**任意**的基础类型，矩阵，数字，字符串。

值得**注意**的是它的下标起始是$1$不是$0$

##### 结构体

- 定义
```
A = struct('name',{{'element1','element2'}},"name2","element")
```
- 调用
    - 基础是 A.name
    - 调取$n$号元素 $A.name(n)$，取出来是一个$cell$类型的东西
    - 而$A.name{n}$取出具体值，可以是任意数据类型

### Matlab绘图

#### 平面绘图

##### 二维平面绘图

- 绘制一个图像
  - 绘图前是先要设**初始值**的，如$x = 0:0.01:2*pi(即\pi)$
    $y = sin(x)$
  - 建立一个**幕布** $figure$
  - **绘制图像** $plot(x,y)$
    - 一个幕布上可以绘制多个图像，具体操作参考下方：

```
        x = 0:0.01:2*pi;
        y1 = sin(x);
        y2 = cos(x);
        figure
        [AX,H1,H2] = plotyy(x,y1,x,y2,'plot'); /* 此处plotyy是共用一个坐标系，在y上有不同的取值 */
        set(get(AX(1),'Ylabel'),'String','Slow Decay')
        set(get(AX(2),'Ylabel'),'String','Fast Decay')
        xlabel('Time (\musec)')
        title("Multiple Decay Rates")
        set(H1,'LineStyle','--')
        set(H2,'LineStyle',':')
        set(H1,'color','b')
        set(H2,'color','k')

```
有关其中的$AX$和$H$ [^2]
  - **命名当前图像** $title('name')$
  - 设置**横纵坐标名字** $xlabel('name')$ 和 $ylabel('name')$
  - **限制图像的范围** $xlim(the limit)$ 和 $ylim(the limit)$
- 个性化设置
    - **颜色参数** $('color')$
        | 红 | 绿 | 蓝 | 黄 |
        | :--: | :--: | :--: | :--: |
        | r | g | b | y |
        | 粉红 | 青 | 白 | 黑 |
        | m | c | w | k |
    - **线形参数** $('LineStyle')$
        | 实线 | 虚线 | 冒号线 | 点画线 |
        | :--: | :--: | :--: | :--: |
        | - | -- | : | -. |
    - **数据标记点**
        常用的有：点$(.)$、十字$(+)$、圆圈$(o)$、星号$(*)$、叉$(x)$、正方形$(s)$、菱形$(d)$、各种三角形$(^ > < v)$ 剩下的自己百度
        [![spot.png](https://s21.ax1x.com/2024/10/01/pA380gS.png)](https://imgse.com/i/pA380gS)

##### 三维绘图

基本流程与二维相似，只是部分的函数名称换了而已
先贴一个~~网上抄的~~例子

```
t = 0:pi/50:10*pi;
plot3(sin(t),cos(t),t)
xlabel('sin(t)')
ylabel('cos(t)')
zlabel('t')
grid on
axis suqare
```
解释：
- $plot3$ **建立三维图像**
- $label$ **命名**（
- $gird$ $on$ **增加网格**
- $axis$ $square$ 将坐标平面**控制为正方形**
- 补充：$hold$ $on$: 在当前幕布上**继续**作画 
    $hold$ $off$: **结束**当前幕布的绘制

而若想绘制出**面**，则应用$mesh$ 和 $surf$ 其中$surf$给面**染色**，而$mesh$不染，两者用法类似，下面则以$mesh$为例
- $mesh(x,y,z)$ 以$(x,y,z)$为坐标进行绘图
- $mesh(A)$ 其中$A$是矩阵，然后以矩阵中每个元素$z$对应$(x,y)$形成$(x,y,z)$进行绘图

##### 杂技(此杂技非彼杂技)

- $magic(n)$
    生成一个n阶的**幻方**
    $B = a$ $:$ $b:c$
    生成一个从$a$到$c$以$b$为公差的等差数列(类型是矩阵)
- $peaks(n)$ 返回值是一系列坐标，绘制出来是一个**凹凸有致的曲面**，包含三个局部极大值点和局部极小值点
- $on$就是开启，$off$就是关闭
- $hidden$**隐藏**，但我想说$hidden$ $off$这样就能达到**透视**的效果



- [^1]: 实际上就是乘以$B$的逆
- [^2]: 均是指句柄，也就是常说的指针。AX(1)是设置左边纵轴，AX(2)是右边。对于H1H2则是图形的句柄，此处对应两条曲线
